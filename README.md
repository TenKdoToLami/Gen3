# Gen3 Trading Bot - Production Environment

This repository is a clean, production-focused implementation of the **Gen3 Precision Binary Strategy** (3xSPY vs CASH). It has been stripped of research clutter and optimized for daily execution.

## 📁 Structure
- `config/`: Contains `v3_champion.json` (The DNA of the bot).
- `data/`: Local cache of historical market data.
- `logs/`: History of generated signals and rebalances.
- `src/`: Core logic (Indicators, Data Fetchers, Strategy).
- `scripts/`: Your operational entry points.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
pip install pandas yfinance alpaca-trade-api python-dotenv
```

### 2. Configure Environment
Create a `.env` file inside the `config/` directory and fill in your Alpaca keys:
```bash
# Example content for config/.env
ALPACA_KEY=your_key
ALPACA_SECRET=your_secret
TICKER_3X=SPXL
TICKER_SIGNAL=VOO
STRATEGY_DNA=config/v3_champion.json
```

### 2. Generate Today's Signal
Run this script every morning or after market close to get the definitive trade for the next session.
```bash
python scripts/get_signal.py
```
This script will:
1. Download the latest SPY, VIX, and Yield Curve data.
2. Run the data through the V3 Champion DNA.
3. Output a **VERDICT**: `3xSPY` or `CASH`.
4. Log the signal to `logs/signal_history.csv`.

### 3. Verify the Strategy
To see the full institutional-grade historical backtest (1993 - Present):
```bash
python scripts/full_backtest.py
```

### 🧪 Command Center (control.py)
The root `control.py` script allows you to run specific parts of the bot using simple commands.
*   `python control.py status` : Check if the market is open.
*   `python control.py sync` : Update historical data (YFinance/FRED).
*   `python control.py signal` : Calculate today's trading signal.
*   `python control.py balance` : Check account cash and equity.
*   `python control.py rebalance` : Run the **Full Cycle** (Sync -> Signal -> Sell -> Buy).

### 🤖 Automation (Linux/VPS)
To automate the bot every weekday at 21:50 Prague time (10 minutes before NY close):
```bash
# Add to crontab
python scripts/manage_cron.py add

# Remove from crontab
python scripts/manage_cron.py remove
```
You can check the logs for the automated runs in `logs/cron.log`.
